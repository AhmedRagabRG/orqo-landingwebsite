# Prioritized 30/60/90-day SEO roadmap

Start the clock after an approved production release. Priorities depend on evidence, not a promised ranking timetable. No accounts, submissions or outreach are authorized by this roadmap itself.

## First 30 days — release, establish measurement, validate demand

| Priority | Action | Owner / dependency | Completion evidence |
| --- | --- | --- | --- |
| P0 | Review actual product capabilities, Arabic/English copy and comparison source freshness; approve release separately | Product owner and marketing reviewer | Reviewed content inventory, explicit deployment approval |
| P0 | Verify the existing GA/Clarity project ownership and privacy choices; configure Search Console | Analytics/site owner, account/DNS access | Ownership confirmed; correct stream and consent behavior in live DebugView |
| P0 | Deploy after approval and validate preferred domain, HTTPS, `/en`, trailing slash and missing-route behavior | Hosting owner | Correct HTTP redirects/statuses and no loops; preserve query parameters intentionally |
| P1 | Submit canonical sitemap and inspect representative localized URLs | Search Console owner | Sitemap processed and coverage reviewed in the actual account; do not infer indexing from HTTP 200 |
| P1 | Test live contact relay with an owner-approved message and real signup attribution if app analytics permits | Site and app owners | Known accepted lead; registration completion only if measured in app |
| P1 | Gather baseline organic landing pages, queries and conversion intent by language | Marketing/analytics owner | Report with source, date window and limitations; no invented prior baseline |
| P1 | Interview a few qualified prospects about their inbox/CRM and comparison requirements | Product marketing | Specific questions and objections used to improve existing pages |

## Days 31–60 — improve from real evidence

| Priority | Action | Owner / dependency | Completion evidence |
| --- | --- | --- | --- |
| P1 | Review query/page overlap and improve the existing owning pages before adding routes | SEO/editorial owner, sufficient Search Console data | Query-to-page map updated; no unnecessary duplicate intent |
| P1 | Refresh competitor capabilities and billing-model claims | Editorial/product owner | Official sources rechecked and visible reviewed dates updated after actual work |
| P1 | Publish a permissioned customer workflow case study | Customer permission, verified evidence | Clear workflow and caveats; measurable outcomes only when supported |
| P2 | Research and write WhatsApp Business App vs Platform and CRM-selection guides if existing demand supports them | Editorial owner, current official policies | Original, reviewed bilingual content that answers a distinct question |
| P2 | Review measured unused global CSS and route-specific JS with coverage and visual comparisons | Frontend owner | Reduced delivered bytes without mobile, dark-mode or interaction regressions |
| P2 | Evaluate a G2/Capterra product listing through the current vendor workflow | Authorized owner; current program eligibility | Accurate approved listing; no fabricated reviews or paid ranking claims |

## Days 61–90 — extend proven clusters

| Priority | Action | Owner / dependency | Completion evidence |
| --- | --- | --- | --- |
| P1 | Review qualified leads and actual registration outcomes where available | Marketing and app analytics owners | Landing-page/language trends with attribution and consent limits |
| P1 | Improve pages receiving relevant impressions but weak engagement | SEO/editorial owner | Revised titles/content addressing observed intent, with an annotated release |
| P2 | Add a distinct Intercom, SleekFlow, Trengo, Chatwoot or Kommo comparison only where prospects request it | Deep official-source verification | Useful product-specific content, bilingual parity, source date and fair fit guidance |
| P2 | Validate dedicated Instagram/Messenger or Web Chat pages if product evidence and unique intent justify them | Product owner and real account demo | Supported actions documented; no unsupported channel or trigger claims |
| P2 | Explore partner documentation/community contributions with permission | Integration evidence and outreach authorization | Useful published material with accurate affiliation disclosure |
| P2 | Review field CWV, crawl/indexing issues and long-term content maintenance | Search Console/CrUX availability | Actual field evidence by device; INP reported only from a suitable field source |

At each review, rerun the build, type checks, SEO regressions and relevant browser checks. Keep the sitemap limited to indexable canonical content. Consolidate overlapping pages when evidence warrants it; do not turn the roadmap into a page-count target.
