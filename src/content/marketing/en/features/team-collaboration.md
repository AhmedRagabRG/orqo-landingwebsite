## A shared inbox needs shared working rules
Putting messages in one tool does not automatically establish ownership. Teams still need to decide who checks new enquiries, who handles specialist questions and what happens at the end of a shift. ORQO provides a shared workspace with conversation assignment and internal notes to support that process.

Start with a small rule: each active conversation has an owner. An assignment tells the next teammate where responsibility sits. A useful note explains the customer's request and the next step rather than simply saying “please handle.”

## Pass context between people and AI
ORQO's existing product presentation includes AI-to-team handover and conversation summaries. Use those capabilities to help a person review the interaction before continuing. A summary is a starting point, so check the original messages when the request involves a complaint or an important commitment.

For example, reception can pass a scheduling enquiry to a colleague with a note about the customer's preferred time. The colleague confirms availability in the scheduling system before replying. This suggested workflow keeps responsibility with the team.

## Build a shift-change checklist
Before a teammate leaves, review active conversations, pending follow-ups and any promises made. Reassign work that needs coverage and record enough context for the next person. Use tags consistently so the team can recognize the same types of requests.

Keep notes relevant and avoid recording unnecessary sensitive information. Internal visibility does not make every detail appropriate to store.

## Test with the people who will use it
In a demo, run a customer enquiry through assignment, a note, a handover and a reply by another teammate. Confirm the number of inbox agents and workspace allowances on your plan. These are separate from general user access, so assess your actual working team against the current pricing details.
